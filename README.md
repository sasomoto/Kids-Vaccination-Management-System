A comprehensive web-based application designed to manage and streamline children's vaccination records. This project leverages Flask for backend development, MySQL for database management, and dynamic web interfaces with integrated triggers and stored procedures for seamless functionality.

Key Features:

Child and Guardian Management: Add, view, and manage records for children and their guardians, ensuring accurate and organized data storage.
Vaccination Tracking: Maintain detailed vaccination history, including vaccine names, providers, and lot numbers, with robust data validation.
Inventory Management: Track vaccine inventories at hospitals and update stock levels dynamically upon vaccination.
Database Integration: Efficient use of MySQL, with advanced triggers to prevent duplicate records and stored procedures for optimized data manipulation.
Dynamic User Interface: Modern and responsive web interface with dropdowns and forms, allowing for seamless user interaction and data entry.
Error Handling and Validation: Ensures data integrity with built-in error handling, input validation, and visual feedback for users.
Technologies Used:

Backend: Flask
Database: MySQL (including triggers, stored procedures, and functions)
Frontend: HTML, CSS (modern styling with responsiveness), and JavaScript
How It Works:
The application provides a structured workflow where users can add vaccination records, manage inventories, and retrieve vaccination history efficiently. Dynamic dropdown menus and form validations enhance user experience, while the backend handles complex data relationships and validations.

Use Cases:

Designed for hospitals, clinics, and public health departments to manage vaccination drives effectively.
Ensures accurate tracking of children's vaccination schedules, inventory levels, and hospital records.
This project demonstrates full-stack development, showcasing database design, backend API creation, and frontend user experience, making it ideal for real-world applications.
